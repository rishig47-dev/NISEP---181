# NISEP-181
## Next-Generation Intelligence for Spacecraft Equipment Preservation

A Python research simulator for civilian reusable-launch-vehicle component recovery. Includes reproducible synthetic data, PyTorch models, training/evaluation, Streamlit dashboard and interactive 3D visualization.

**Research-only:** all trajectories and telemetry are synthetic and illustrative. This is not a flight-dynamics, guidance, landing-control, launch-control or real-world recovery tool. No real vehicle parameters, control laws, actuator outputs or operational instructions are included.

### Architecture
Synthetic mission generator -> telemetry sequences -> LSTM / Transformer forecasting; telemetry rows -> autoencoder anomaly scoring; abstract image tiles -> CNN classification; component summaries -> multi-task recovery/condition classifier; abstract display coordinates -> Plotly 3D mission viewer -> Streamlit dashboard.

### Quick start
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python scripts/generate_data.py --missions 2500 --seed 181
python scripts/train_all.py --epochs 12
python scripts/evaluate_all.py
streamlit run dashboard/app.py
```
Or run the complete workflow: `python main.py --missions 1200 --epochs 8`.

### Models
- LSTM: predicts the next synthetic telemetry feature vector.
- Transformer encoder: same sequence forecasting task for comparison.
- Autoencoder: learns reconstruction of synthetic normal telemetry rows.
- CNN: classifies procedurally generated abstract image tiles (not rocket photographs).
- Multi-head MLP: classifies synthetic recovery outcome and component condition, and estimates an abstract recovery score.

### Dataset
`telemetry.csv`, `mission_summary.csv`, `component_observations.csv`, and `metadata.json` are generated locally. Every feature is normalized and synthetic. Labels are generated by the simulator's own abstract rules, so test scores measure consistency with those rules, not real aerospace performance. Display coordinates are arbitrary plotting coordinates, not physical trajectories.

### Limitations
Do not use results to plan, operate or certify real aerospace vehicles. Any real application requires validated domain models, qualified engineering review, safety assurance and regulatory approval. See `docs/RESEARCH_PLAN.md` for suggested experiments.


## Research-grade extensions

The upgrade package adds dataset validation (`python scripts/validate_dataset.py`), grouped-split and experiment helpers, an uncertainty-summary utility, and research documentation. See `docs/RESEARCH_UPGRADE.md` and `docs/PROJECT_EXPLANATION.md`.

For a defensible research result, run multiple seeds, compare against simple baselines, perform noise and missing-data robustness tests, and report uncertainty. Do not equate synthetic benchmark performance with real aerospace capability.
